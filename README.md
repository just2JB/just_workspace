# just workspace

어두운 도트 우주에서 AI 별들이 협업하는 로컬 웹 대시보드의 **목 버전**입니다.
실제 AI 호출, API 키, 외부 서버는 사용하지 않습니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서:

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 `http://127.0.0.1:5173` 주소를 여세요.

```powershell
npm.cmd run build
npm.cmd run preview
```

핵심 미션 로직 테스트 (Node.js 22.6+):

```powershell
npm.cmd test
```

브라우저 검증 및 빌드의 현재 확인 범위는 [디자인·검증 메모](docs/design.md)를 참고하세요.

## 사용

- 상단 프로젝트 선택 옆 설정 → 프로젝트 생성·수정. 공통 설명·목표·작업 폴더 경로·참고 자료 내용/링크를 저장합니다.
- 선택한 프로젝트 안에서 미션을 생성하고 업무 목록·결과함을 구분합니다. 별·교육 메모는 공용입니다. 별은 프로젝트와 관계없이 동시에 하나의 업무만 수행합니다.
- 우주는 공용으로 모든 실행 중 팀을 표시하고 궤도에 프로젝트 이름을 붙입니다. 프로젝트 전환 중에도 다른 미션은 계속 진행합니다.
- 프로젝트 정보는 시작 시 미션·컨텍스트에 복사됩니다. 프로젝트 자료를 나중에 바꿔도 과거 미션의 기록은 바뀌지 않습니다.
- 현재 폴더·자료는 텍스트로만 저장하며 파일 내용을 자동으로 읽지 않습니다. 기존 미션은 기본 프로젝트로 옮겨 기록을 유지합니다.

- 작은 별 클릭 또는 하단 직원 버튼 → 상세 정보, 최근 7일 완료 건수, 평가 평균
- 기본 별: 폴라리스(총괄), 아카이브(문서), 프리즘(디자인), 펄서(개발). 기존 기본 이름은 기록을 유지한 채 변경됩니다.
- 휴식 구역 없이 자유 배치. 처음 방문한 우주에서는 별이 분산된 무작위 위치에 나타납니다.
- 대기 중인 별 드래그 → 자유 배치 및 위치 저장
- 빈 우주 드래그 / Space+드래그 / 마우스 가운데 버튼 드래그 → 화면 이동
- 스크롤 / 왼쪽 아래 +·− → 포인터 기준 확대·축소 (35~250%), 복귀 버튼 → 기본 화면
- 월드 좌표에서 별을 배치하므로 화면 이동·확대 이후에도 같은 위치를 잡을 수 있습니다.
- 특기 색상: 총괄 골드·문서 민트·디자인 보라·개발 블루·리서치 핑크. 총괄은 팔방 광원 형태로 표시합니다.
- 업무 맡기기 → 업무 입력 → 총괄 1명·참여 별 1개 이상 선택
- 담당 업무와 완료 기준 설정 → 별별 담당 요약·상세 지시 수정. 목 기본값이며 AI가 작성한 분배안은 아닙니다.
- 컨텍스트 미리보기 → 총괄은 전체 상세 분배 내역, 팀원은 자기 상세 지시와 동료 요약만 받는 패킷 확인
- 해당 별의 교육 메모·직무 지침과 이번 미션의 역할 가이드를 분리합니다. 다른 별의 메모는 공유하지 않습니다.
- 업무 시작 시 컨텍스트를 스냅샷으로 저장합니다. 진행 중 업무의 전달 컨텍스트 또는 결과함에서 확인할 수 있고, 이후 교육 수정은 과거 패킷을 바꾸지 않습니다. 현재 패킷은 저장·미리보기용이며 실제 AI 전송은 하지 않습니다.
- 새 미션의 기본 총괄은 폴라리스입니다. 미션마다 다른 별로 변경할 수 있으며 다음 미션은 다시 기본 총괄로 시작합니다. 기본 총괄이 작업 중이면 다른 별을 직접 선택합니다.
- 업무를 시작하면 약 0.85초 동안 빛 꼬리를 남기며 총괄 주변으로 모입니다.
- 수행 중인 총괄은 약 36px, 나머지 별은 약 13px. 클릭 영역은 별 크기와 관계없이 넉넉하게 유지합니다.
- 10초 동안 총괄 주변 궤도에서 작업 → 검토 → 원래 위치로 자동 복귀
- 진행 중 업무의 상단 영역 클릭 → 업무 대시보드. 페이지 새로고침 없이 우주와 대시보드를 오가며 실행이 계속됩니다.
- 대시보드는 별별 대화방(B)으로 구성합니다. 각 방에는 해당 별이 발신·수신한 메시지만 표시하며, 전달 컨텍스트와 담당 업무도 확인할 수 있습니다.
- 신규 목 미션은 분배·응답·결과 보고·검토·최종 보고 메시지를 10초 흐름에 맞춰 기록합니다. 실제 AI 대화가 아닙니다. 기존 미션에는 대화를 소급 생성하지 않습니다.
- 추가 지시는 해당 미션·선택한 별에게만 기록합니다. 현재는 실제 AI로 전송하지 않습니다. 종료 후 지시 입력은 비활성화됩니다.
- 결과함의 업무 대시보드 열기로 완료 후에도 대화 기록을 확인합니다. `#/missions/<id>` 주소와 브라우저 뒤로가기를 지원합니다.
- 별은 동시에 하나의 업무만 수행합니다. 비어 있는 다른 팀으로 추가 미션을 실행할 수 있습니다.
- 업무 중단 → 복귀 (완료 건수에 포함하지 않음)
- 결과함 → 목 결과 확인·기록 다운로드·직원별 1~5점 평가
- 총괄 평가는 자동 AI 평가가 아니라 사용자가 직접 입력하는 **목 항목**입니다. 총괄의 자기 평가는 제외합니다.
- 새로운 별 만들기 → 문서·디자인·개발·리서치·총괄 템플릿 선택 → 이름 지정
- 별 프로필의 교육·메모 → 교육 입력 → 수정 가능한 메모 초안 → 사용자 확인 후 저장
- 현재 교육은 AI 요약이 아닌 목 흐름입니다. 입력 문장을 초안으로 옮기며, 저장을 눌러야 해당 별의 메모에 반영합니다. 초안 취소/창 닫기는 메모를 저장하지 않습니다.
- 저장된 메모는 별별로 수정·삭제·새로고침 후 복구가 가능합니다. 모델의 실제 업무 적용은 AI 연결 이후 구현합니다.
- 설정 → 움직임 줄이기

## 저장과 제한

직원·배치·업무·평가는 현재 브라우저의 localStorage(`just-workspace.v1`)에 저장됩니다. 새로고침 후에도 10초 종료 시점을 기준으로 복구합니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다. 다른 기기나 브라우저와 동기화되지 않습니다.

폰트는 시스템 고딕체를 사용하며, 인터넷이 되면 Google Fonts의 Noto Sans KR을 불러옵니다. 외부 AI는 호출하지 않습니다. 캐릭터·우주는 Canvas 픽셀 그래픽으로 렌더링합니다. 움직임 줄이기에서는 궤도 회전과 별의 부유를 멈추지만 업무는 정상 종료합니다.

실제 Codex/Claude 연결, 백엔드·SQLite, 파일 분석·결과물 생성은 이 목 버전에 포함되지 않습니다.
