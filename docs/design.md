# UI 방향

기준: `space-concept.png` (내장 Image Gen으로 생성한 우주 오피스 시안).

사용자의 후속 수정 사항을 반영:

- 사람 대신 작은 빛나는 도트 별
- 기본 표시를 작은 별과 이름으로 축소, 클릭하면 오른쪽 상세 패널
- 총괄과 참여 별을 고르면 총괄 주변의 궤도로 팀 구성
- 목 미션은 10초 후 종료하고 대기 좌표로 복귀
- 휴식 궤도 영역 삭제. 별들은 공간에 분산 배치합니다.
- 미션 총괄만 크게(약 36px), 나머지는 작게(약 13px), 0.85초 가속 이동과 픽셀 빛 꼬리
- 기본 이름은 폴라리스·아카이브·프리즘·펄서. 기존 사용자 기록 및 직접 만든 이름 보존
- 소개 제목과 설명 제거. 캔버스 드래그 이동·포인터 기준 확대/축소·초기화 컨트롤 추가
- 특기별 색상 적용, 총괄은 팔방 광원 모양. 별 드래그와 카메라 이동은 서로 다른 좌표로 처리
- 확정: 기본 총괄은 폴라리스, 미션별 변경 가능(C). 프로필 선택은 기본 총괄을 바꾸지 않습니다. 기본 총괄이 바쁘면 사용자가 다른 별을 선택합니다.
- 확정: 별은 직무 템플릿으로 생성(B). 교육 내용을 메모 초안으로 제안하고 사용자가 수정·저장(C)합니다.
- 현재 교육 화면은 AI를 호출하지 않습니다. 입력문을 초안으로 가져오는 목 흐름이며, 저장한 메모만 별별 데이터에 보존합니다. 실제 요약과 업무 적용은 후속 AI 연결 범위입니다.
- 확정: 총괄은 전체 상세 분배 내역, 팀원은 자기 상세 지시와 동료 담당 요약(C). 각 별의 교육 메모는 자신의 패킷에만 포함합니다.
- 목 분배안의 요약·상세 지시·완료 기준을 수정하고 패킷을 미리 볼 수 있습니다. 시작 시 저장한 패킷은 이후 교육 내용 변경에 영향받지 않습니다. 실제 AI 전송은 연결 이후 범위입니다.
- 확정: 업무 클릭 → 업무 대시보드. 대화는 별별 방(B)으로 분리하고 각 방의 발신·수신 메시지만 표시합니다. 신규 미션에만 목 대화 단계를 기록하며 기존 기록은 소급 생성하지 않습니다.
- 확정: 프로젝트 중심(B). 프로젝트에 설명·작업 폴더·참고 자료를 저장하고 미션 생성 시 포함합니다. 별과 교육은 공용, 업무 목록·결과함은 프로젝트별, 실행 관리는 전체 미션 기준입니다. 실제 파일 읽기는 후속 연결 범위입니다.

## 토큰과 구성

- 배경 `#090c12`, 패널 `#0e121a`, 선 `#232a35`, 기본 글자 `#e6e9f0`
- 버튼 `#eeeee9`, 명도 차이로 상태 구분
- 본문: Noto Sans KR / 시스템 고딕, 영어 보조 UI: Segoe UI
- 6~10px 모서리, 얇은 경계, 작은 글로우, 픽셀 별·달
- 상단 바 / 좌측 우주 Canvas / 하단 키보드 접근 가능한 직원 선택 / 우측 기능 패널
- 모바일: 우주 위, 상세 패널 아래로 배치

## 시안과의 의도된 차이

상시 캐릭터 옆 정보는 사용자의 요청에 따라 상세 패널로 이동했습니다. 우주 화면을 비워 두고 선택을 돕기 위해 하단 직원 선택 버튼을 추가했습니다. 배경과 별은 확대·축소와 움직임 제어를 위해 Canvas로 그립니다. 시안 이미지는 런타임 배경으로 사용하지 않습니다.

## 검증 경계

PR 준비 시 `npm.cmd test`의 로직 테스트 23개와 TypeScript 검사가 통과했습니다. 최초 구현의 Vite 빌드는 성공했지만, 현재 코드의 `npm.cmd run build`는 1,594개 모듈 변환 후 상세 오류 없이 종료 코드 1로 끝납니다. 권한을 높인 재실행과 디버그 출력에서도 같은 증상이 반복되어 최종 프로덕션 빌드는 미확인입니다. 개발 서버의 HTTP 200 응답은 이전 구현 단계에서 확인했습니다. Playwright 실행은 이전 권한 요청이 거절되어 렌더링·콘솔·실제 클릭·드래그·확대축소·궤도 복귀 애니메이션·모바일 외관을 확인하지 못했습니다. 시각적 일치 검증은 미완료입니다.
